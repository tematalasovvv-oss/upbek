# UpBek — жизнь как РПГ

Калории, деньги, сон и прокачка героя. PWA для iPhone без App Store.

**Открыть:** https://tematalasovvv-oss.github.io/upbek/

## Установка на iPhone
1. Открой ссылку в **Safari**.
2. «Поделиться» ⬆︎ → **«На экран „Домой“»** → «Добавить».

## Как устроено
- `index.html`, `style.css`, `theme.css`: интерфейс и темы («Классика», «Комикс»).
- `data.js`: блюда, категории, банки.
- `app.js`: логика приложения, квесты, уровни.
- `sync.js`: облачная копия (зашифрована на телефоне) и события из «Команд» iPhone (сон, SMS банков).
- `supabase.sql`: схема сервера (Supabase, бесплатный тариф). Таблицы закрыты, доступ только через функции по личному коду.
- `config.js`: адрес сервера и публичный (publishable) ключ.
