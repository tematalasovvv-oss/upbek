# UpBek — жизнь как РПГ

Калории, деньги и прокачка героя. Работает как приложение на iPhone (PWA), без App Store.

## Как поставить на iPhone

Сайт должен быть доступен по интернету (https). Проще всего так:

### Вариант 1. Netlify (5 минут, бесплатно)
1. Зайди на https://app.netlify.com/drop с компьютера и войди (через Google или GitHub).
2. Перетащи туда **всю папку `Upbek`**.
3. Получишь ссылку вида `https://что-то.netlify.app`. В настройках сайта (Site configuration → Change site name) можно поменять её на `upbek-tema.netlify.app`.
4. Чтобы обновить сайт, перетащи папку ещё раз (Deploys → перетащить).

### Вариант 2. GitHub Pages
1. Создай репозиторий, загрузи в него файлы из этой папки.
2. Settings → Pages → Deploy from branch → `main` / root.

### На телефоне
1. Открой ссылку в **Safari** (именно в Safari).
2. «Поделиться» ⬆︎ → **«На экран „Домой“»** → «Добавить».
3. Запускай UpBek с иконки. Данные хранятся на телефоне.

Девушке достаточно отправить ту же ссылку: у неё будет свой герой и свои данные.

## Советы для скорости
- **Трата:** ＋ → Расход → сумма → категория. Всё, 3 касания. Не помнишь, на что потратил? Жми «❓ Потом» и разберёшь позже.
- **Забыл записывать несколько дней:** Казна → «🧮 Сверка», впиши реальный баланс из банка, и разница запишется сама.
- **Еда:** нажми плитку (1 касание) или напиши текстом: «2 яйца, пол лепёшки, чай». Лень считать? Есть кнопки «Перекус / Обычно / Плотно / Пир».
- **Резервная копия:** Ещё → «Резервная копия», раз в неделю.
